# 🌐 Desafio de Projeto: Primeiros Passos com HTML

Este repositório contém a resolução do **Desafio de Projeto - Módulo I: Primeiros Passos com HTML**, desenvolvido durante o bootcamp/curso da **DIO (Digital Innovation One)**.

O objetivo do projeto é construir uma página web estática e bem estruturada, aplicando na prática conceitos fundamentais da linguagem de marcação **HTML5**, além de explorar tags clássicas e modernas de formatação de texto.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Linguagem de Marcação de Hipertexto)
- Estruturação semântica e tags de formatação padrão W3C

---

## 📌 Funcionalidades e Aprendizados

Durante a elaboração deste projeto, foram colocados em prática os seguintes conceitos:

1. **Navegação Interna (Âncoras):**
   - Criação de um **Índice Interativo** com links (`<a>`) apontando para IDs específicos no documento (`#id`).
   - Implementação do recurso "Voltar ao topo" no final de cada seção.

2. **Hierarquia e Estruturação de Conteúdo:**
   - Utilização das tags de cabeçalho (`<h1>` até `<h6>`) para definir a ordem de relevância do conteúdo.
   - Divisão visual de seções com a tag de linha horizontal (`<hr>`).

3. **Listas e Organização:**
   - Uso de listas ordenadas (`<ol>`) para passos sequenciais.
   - Uso de listas não ordenadas (`<ul>`) para agrupamento de itens sem ordem específica.

4. **Formatação de Texto e Semântica:**
   - Textos em **negrito** (`<strong>`), *itálico* (`<i>`) e <u>sublinhado</u> (`<u>`).
   - Destaque visual com `<mark>` e redução de escala para notas secundárias com `<small>`.
   - Fórmulas e anotações utilizando subscrito (`<sub>`) e sobrescrito (`<sup>`).
   - Citações em bloco com `<blockquote>`.

5. **Pesquisa e Aplicação de Novas Tags:**
   - `<abbr>`: Exibição do significado estendido de siglas e abreviações ao passar o ponteiro do mouse.
   - `<del>`: Representação visual de textos e informações tachadas/deletadas.
   - `<font>`: Uso demonstrativo da tag legada de estilização de fontes.

6. **Links Externos:**
   - Redirecionamento para sites de referência técnica (como W3C e MDN) configurados para abrir em uma nova guia (`target="_blank"`).
